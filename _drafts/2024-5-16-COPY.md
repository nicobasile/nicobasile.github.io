## ⚙️ Implementation Details

* Base framework: **NVIDIA Voyager** (code‑generating LLM + auto‑curriculum)
* Added modules: memory encoder, episodic retriever, hierarchical planner
* State summarization via compact world‑state encodings
* Tool‑use affordances stored in a symbolic key‑value structure
* Long‑horizon goals solved using automatic decomposition heuristics
* All modules integrated into Voyager’s prompt stack and action‑generation loop

---

## 🧭 Challenges & Lessons Learned

* **Hallucination control:** required tight state‑validation checks for LLM‑generated code.
* **Memory pruning:** naive episodic logs grow unbounded → implemented scoring/forgetting.
* **Transition oscillation:** without hierarchical plans, agents loop on incomplete subgoals.
* **Tool‑use brittleness:** required modeling tool durability & affordances explicitly.

The biggest insight: *Long‑horizon behavior emerges only when an agent can both remember the past and simulate several futures.*
